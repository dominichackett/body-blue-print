#Body Blueprint - AI-Powered Fitness Companion


## 🏆 Hackathon Project
Body Blueprint was created for the **AI Blueprints with Filecoin Hackathon**. It's a comprehensive fitness ecosystem that combines AI-powered health tracking with decentralized data storage.

## 📱 Key Features

### Mobile Application (React Native with Expo)
- **Macro Calculator**: Personalized nutrition calculations based on health goals
- **AI Personal Trainer**: Custom workout plans generated by AI
- **Smart Meal Planning**: AI-generated meal plans tailored to your macros
- **Food Recognition**: Camera-based calorie tracking using image recognition
- **DAO Integration**: Participate in the fitness community DAO

### Backend Services
- **Node.js Server**: Facilitates data uploads to Akave/Filecoin
- **Data DAO**: Decentralized community governance of fitness data

### Web Interface (Next.js)
- **DAO Dashboard**: Participate in community governance
- **Data Marketplace**: Access shared fitness data for research and ML projects

## 🏆 Bounty Integrations

### 1. Akave Decentralized Storage
Our Node.js server ([akaveserver](https://github.com/dominichackett/akaveserver)) handles all Filecoin storage operations via Akave's API, featuring:
- End-to-end encrypted fitness data storage
- Content addressing with IPFS CIDs
- Automatic backup scheduling

[View Akave Integration Details](akave.md)

### 2. Lilypad Inference
Integrated directly in the mobile app for:
- Private meal analysis without centralized servers
- Verifiable workout generation
- On-chain proof of all AI operations

[View Lilypad Integration Details](lilypad.md)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or later)
- Expo CLI (`npm install -g expo-cli`)
- Yarn or npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/body-blueprint.git
   cd body-blueprint
   ```

2. Install dependencies:
   ```bash
   yarn install
   # or
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory based on `.env.example`

### Running the App
```bash
expo start
```

Scan the QR code with the Expo Go app on your iOS or Android device, or run on an emulator.

## 🌐 Backend Setup
The Node.js server for Filecoin/Akave integration is located in the `/server` directory.

1. Navigate to the server directory:
   ```bash
   cd server
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   node index.js
   ```

## 📊 Tech Stack
- **Frontend**: React Native (Expo)
- **State Management**: Redux or Context API
- **Backend**: Node.js
- **Web Interface**: Next.js
- **Decentralized Storage**: Filecoin via Akave
- **AI Services**: (llam3 via Lilypad (Meal Plans,Exercises), Gemini 2.5 Pro Google)
